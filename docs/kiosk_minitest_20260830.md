- [ ] 貯金箱(現金入れ)
- [ ] 商品(シグネチャーTシャツ。全部でなくても数枚あれば成立)
- [ ] 手書きでいいので卓上ポップ2枚:「現金はこちらへ(おつりは出ません)」「お支払い後に商品をお持ちください」

## 会場でのセットアップ(5分・詳細は kiosk_ipad_guide.md)

- [ ] iPadを会場Wi-Fiかテザリングに接続
- [ ] Safariで https://bw5-app.vercel.app/kiosk を開く(商品が出ればOK)
- [ ] 自動ロック「なし」・明るさ最大
- [ ] トリプルクリック→ガイドアクセス開始

## テストする観点(レッスンの合間に自分で1周)

- [ ] 現金フロー: 商品→カゴ→「現金」→確認→完了画面→自動リセット
- [ ] QRフロー: 「カード/PayPay/Apple Pay」→QR表示→自分のスマホで読んで少額決済
      →iPadが自動で完了画面に変わるか(その場で返金するので金額はTシャツでもOK)
- [ ] QR放置: QRを出したまま5分待つ→自動で最初に戻るか
- [ ] 買った直後の在庫: /staff/kiosk(スマホでOK)で在庫・売上が合っているか
- [ ] 誤操作リカバリ: 現金をわざと1件誤タップ→スタッフ画面から取消→在庫が戻るか
- [ ] (余裕があれば)Wi-Fiを切って「現金でお願いします」画面に切り替わるか→復帰するか
