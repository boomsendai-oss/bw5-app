# 無人物販kiosk iPad設営ガイド(TARO向け)

イベント会場でiPadをセルフレジとして設置するときの手順。所要15分。
初回はレッスン会場のミニ運用テスト前に一度通しでやっておくと本番が楽です。

## 0. 事前にスタッフ画面で準備(前日まで)

1. https://bw5-app.vercel.app/staff/kiosk を開く(スタッフパスワード)
2. 「販売会」タブ → 新しい販売会を作成(例: BF6 会場グッズ販売・2026-09-26)
3. 「商品・在庫」タブ → 商品を追加(名前・価格・写真・在庫。Tシャツはサイズを追加して在庫はサイズごとに入れる)
4. 販売会セレクタ横の「この販売会をiPadに表示」を押す(●iPad表示中になればOK)

## 1. iPad本体の設定(当日・会場で)

### 1-1. 通信の確保
- 会場Wi-Fiに接続するか、スマホのテザリングにつなぐ
- Safariで https://bw5-app.vercel.app/kiosk を開いて商品が出ることを確認

### 1-2. 画面が消えない設定
- 設定 → 画面表示と明るさ → 自動ロック → **「なし」**
- 明るさは最大付近に(会場は明るいため)
- 設定 → 通知 → おやすみモード(集中モード)をON にすると通知ポップアップが出ない

### 1-3. ガイドアクセスを有効化(お客さんが他のアプリに行けないようにする)
1. 設定 → アクセシビリティ → **ガイドアクセス** → オン
2. 「パスコード設定」→ ガイドアクセスのパスコードを設定
   (TAROだけが知る4〜6桁。**iPad本体のパスコードとは別物**)
3. 「ショートカット」がオンになっていることを確認(トリプルクリックで起動するため)

## 2. レジとして起動する

1. Safariで https://bw5-app.vercel.app/kiosk を開く
2. 共有ボタン → 「ホーム画面に追加」で追加し、ホーム画面のアイコンから開くと
   アドレスバーが消えて全画面になる(推奨。Safariのままでも動作はする)
3. **トップボタン(またはホームボタン)を素早く3回押す** → ガイドアクセス開始画面
4. 左下「オプション」で以下をオフにする:
   - スリープ/スリープ解除ボタン: オフ(誤操作で画面を消されない)
   - 音量ボタン: オフ
   - キーボード: オフ
   - 「時間制限」は設定しない
5. 右上「開始」→「ガイドアクセスを開始しました」と出たら設営完了

これでお客さんは /kiosk 以外の操作ができなくなります。

## 3. 終了するとき

1. トリプルクリック → ガイドアクセスのパスコードを入力 → 左上「終了」
2. スタッフ画面 /staff/kiosk の「売上」タブで内容確認・CSVダウンロード
3. 貯金箱の現金と「現金(貯金箱)」の金額を突合する

## 4. 会場での運用メモ

- **貯金箱**はiPadの横に置き、「現金はこちらへ(おつりは出ません)」のポップを添える
- 商品はiPadの近くに並べ、「お支払い後にお持ちください」のポップを添える
- **現金の誤タップ**があったら: スタッフ画面 → 売上タブ → 該当注文の「取消」(在庫も戻る)
- **在庫がズレたら**: 商品・在庫タブで実数を数えて「補正」で上書き
- QRを読んだのに支払わず去った場合: 5分で自動的に画面が戻り、在庫の仮押さえも解放される。何もしなくてよい

## 5. トラブル時

| 症状 | 対処 |
|---|---|
| iPadに「オンライン決済がご利用いただけません」 | 通信が切れている。Wi-Fi/テザリングを確認。復帰すると自動で戻る。その間は現金運用 |
| QRを読んでも決済画面が開かないとお客さんに言われた | お客さんのスマホの通信の問題が多い。現金をご案内 |
| 「⚠️金額ズレ」「⚠️期限切れ後入金」が売上タブに出る | 入金自体はされている。イベント後に注文明細とStripeダッシュボードを突合(放置でも売上計上は正しい) |
| 画面が固まった | トリプルクリック→パスコード→終了→Safariを開き直し→再度ガイドアクセス |
