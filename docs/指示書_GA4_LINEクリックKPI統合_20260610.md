1. **LINEクリック総数** — boom-sendai.com（現行Wixサイト）上のLINEリンク（lin.ee / line.me）が押された回数。流入元を問わない全体数

Google Ads APIは開発者トークン審査が必要で重い。**GA4 Data API（無料・審査不要）だけで両方の数字が取れる**：

- 総数：`runReport` で metric `eventCount`、dimensionFilter `eventName == line_click`
- 広告経由：上記に加えて dimension `sessionSourceMedium` のフィルタ `== "google / cpc"` を追加
  - （日別推移を出すなら dimension に `date` を追加）

Node実装は `@google-analytics/data` パッケージの `BetaAnalyticsDataClient` が定番。プロパティ指定は `properties/410842576`。
